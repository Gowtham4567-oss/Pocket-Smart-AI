# PocketSmart AI

PocketSmart AI is a GenAI-powered budget and recommendation assistant.

It supports:

- Home Interior Planning
- Party Budget Planning
- Jewelry Recommendations
- Optional Jewelry Outfit Image Analysis
- Budget Allocation
- Recommendation History
- User Registration and Login
- Gemini AI Integration
- Platform Search Links

# PocketSmart AI

### AI-Powered Personal Budget & Shopping Recommendation System

## Objective

To develop an intelligent and user-friendly system that helps users make **smart, personalized, and budget-conscious shopping decisions** using Artificial Intelligence.

## Workflow

```text
Login
  ↓
Select Planner
  ↓
Enter Budget & Preferences
  ↓
AI Recommendation
  ↓
View Personalized Suggestions
  ↓
Save Recommendation History
```

## Project Outcome

PocketSmart AI provides users with a simple and intelligent way to manage their shopping plans while staying within their desired budget.
